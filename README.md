**AI-Powered ETL Automation Using n8n**

As part of my Generative AI learning journey, I completed an end-to-end ETL automation workflow using n8n, OpenAI, and Google Drive.

The workflow downloads student enrollment data from Google Drive, extracts 50 CSV records, uses OpenAI to clean and standardize the data, converts the AI output into structured records using JavaScript, and generates a cleaned CSV file.

The cleaned file is then automatically uploaded back to Google Drive.

**Key Learnings:**
- Building automated ETL pipelines using n8n
- Integrating OpenAI with workflow automation
- Processing CSV and JSON data
- Using JavaScript for data transformation
- Connecting Google Drive for file operations

Successfully executed and tested the complete workflow.

This assignment helped me understand how AI can be integrated into real-world data processing and automation tasks.
